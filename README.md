# DSA Algorithm Visualizer

An interactive web-based visualizer that demonstrates how common **Data Structures and Algorithms** work through animations.

The project allows users to generate random arrays, select an algorithm, and observe comparisons, swaps, and search operations step by step.

---

## Features

-  Generate random arrays
-  Visualize Bubble Sort
-  Visualize Selection Sort
-  Visualize Insertion Sort
-  Visualize Linear Search
-  Visualize Binary Search
-  Start algorithm animations
-  Pause and resume animations
-  Reset the array
-  Control animation speed
-  Adjust array size
-  Track number of comparisons
-  Track number of swaps
-  Highlight sorted elements
-  Highlight elements being compared
-  Highlight the current minimum
-  Highlight found elements
-  Responsive interface
